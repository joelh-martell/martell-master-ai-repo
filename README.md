# martell-master-ai-repo
The complete repository of all Martell Group prompts, agents, workflows, and tools for how we run the business with AI.

Folders are business functions. Add another folder when a prompt does not fit a function that is already here.

Each file says what it is for, when to use it, the prompt, and how to use it.

[CHECKLIST.md](CHECKLIST.md) is the list of uses we know about but do not have the prompt text for yet.
