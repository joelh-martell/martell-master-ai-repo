# Reverse-engineer a result

## What this is for
Start from the result you want and work backward into steps and principles.

## When to use it
When you can see the outcome and cannot see the path.

## The prompt
```
Context: I’m trying to master [insert topic] and need to unpack how it really works.
Role: You’re a systems architect who reverse engineers success.
Command: Start with the end result and work backwards, breaking the topic into logical building blocks I can apply.
Format: Present as a numbered breakdown, from outcome → steps → principles.
```

## How to use it
1. Replace [insert topic].
2. Paste the prompt.
3. Use the numbered breakdown as the working plan.
