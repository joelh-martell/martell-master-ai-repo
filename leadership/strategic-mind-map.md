# Strategic mind map

## What this is for
A structured mind map of a topic so you can decide faster.

## When to use it
When a topic is too tangled to hold in your head and you need the branches, not a summary paragraph.

## The prompt
```
Context: I’m working to deeply understand and visualize [insert topic] so I can make better, faster decisions.
Role: You are a world-class strategist and systems thinker.
Command: Build me a clear and organized strategic mind map. Start from the core idea and break it into high-leverage branches, subtopics, and actionable connections.
Format: Present as a structured list I can easily turn into a visual map or slide deck.
```

## How to use it
1. Replace [insert topic].
2. Paste the four lines together.
3. Turn the list into a map or slides if you need to show it.
