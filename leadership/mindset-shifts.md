# Mindset shifts when you are stuck

## What this is for
Five mindset shifts and one action when you are avoiding hard work or stuck on a plateau.

## When to use it
When the block is you, not a missing document.

## The prompt
```
Context: I’m hitting friction with [insert topic] and need to build mental resilience fast.
Role: You’re a mindset coach for elite founders.
Command: Give me 5 battle-tested mindset shifts to help me lean into discomfort, push past plateaus, and level up.
Format: Bullet points with a one-liner explanation for each shift, plus one action step to lock it in.
```

## How to use it
1. Replace [insert topic] with the thing you are avoiding.
2. Paste the prompt.
3. Do the one action step.
