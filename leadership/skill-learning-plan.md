# Skill learning plan

## What this is for
Turn time you just freed up into a learning plan for the two skills that move one goal, and put that time on the calendar.

## When to use it
Right after a calendar cleanup, when the open blocks are still visible and you have one goal for the next year.

## The prompt
```
I just freed up time and I want to fill it with growth. My biggest goal for the next 12 months is [GOAL]. What are the 2 highest leverage skills I should learn? Put together a learning plan, and schedule daily time to work on it, including putting links to resources in the calendar.
```

## How to use it
1. Name one goal, not three.
2. Paste the prompt with that goal filled in.
3. Let it book recurring learning time.
4. Treat that block like a client meeting.
