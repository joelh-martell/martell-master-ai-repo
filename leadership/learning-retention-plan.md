# Learning retention plan

## What this is for
A checklist to remember and use what you just learned, instead of rereading it.

## When to use it
After a course, book, or research session you do not want to lose.

## The prompt
```
Context: I want to retain and apply what I learn about [insert topic] without re-reading it 10x.
Role: You’re a peak performance coach for learning and memory.
Command: Build me a learning plan that sticks—include tools like spaced repetition, story-based recall, and visual triggers.
Format: Step-by-step checklist I can follow after each learning session.
```

## How to use it
1. Replace [insert topic].
2. Paste the prompt.
3. Run the checklist at the end of the next session.
