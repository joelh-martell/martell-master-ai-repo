# Task playbook from a recording

## What this is for
Turn one narrated recording of a task into an SOP, a definition of done, and a one-page checklist so someone else can do it without you.

## When to use it
The next time you do a repeatable task you want off your plate.

## The prompt
```
I need a playbook for my team to complete [task] without error and without needing me. Here's the transcript of me doing it. Write the SOP, a clear definition of done, and a one-page checklist. Create as a Google Doc with headings and bullets to make it simple and clear. [attach transcript]
```

## How to use it
1. Screen-record the task and narrate what you are thinking, not only what you click.
2. Transcribe the recording and replace the brackets.
3. Paste the prompt with the transcript attached.
4. Optional extra line from the same workflow: "Then list the 5 most likely ways someone could get this wrong, and add a guardrail to the checklist for each."
5. Have the person who receives the playbook do the task once and update the doc.
