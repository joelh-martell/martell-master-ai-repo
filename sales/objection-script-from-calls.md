# Objection script from sales calls

## What this is for
Pull objections out of real sales-call transcripts, group them, and write the response script.

## When to use it
After you have a batch of sales call recordings, including both wins and losses.

## The prompt
```
I need to close more deals from sales calls. Analyze these call transcripts and pull out all the objections that the prospect raises. Group common ones together, and then propose the best way to handle each objection. Build the script for me.
```

## How to use it
1. Attach transcripts from recent calls. Include closed-won and closed-lost if you have both.
2. Paste the prompt.
3. Keep the objection list and update it when a new pattern shows up.
