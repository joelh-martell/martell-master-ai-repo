# Support FAQ from the inbox

## What this is for
Group repeat support questions, write an FAQ from the real threads, and name the process change that would have stopped each question.

## When to use it
When the same customer questions keep landing in a support inbox.

## The prompt
```
Read the last 90 days of my support inbox. Find the questions I'm answering over and over, group them, and write an FAQ answering the top 10 (use real information from those threads). Then, for each one, tell me the process or onboarding that would have stopped the question from ever being asked.
```

## How to use it
1. Connect the support inbox.
2. Paste the prompt.
3. Ship the FAQ into onboarding or the help center.
4. Rank the fixes by how many tickets each one would remove, and give that list to the team.
