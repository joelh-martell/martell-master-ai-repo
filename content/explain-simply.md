# Explain it simply

## What this is for
A three-paragraph explainer of a topic, simple enough to teach in a meeting.

## When to use it
When you need to understand something well enough to explain it to someone with no background.

## The prompt
```
Context: I need to internalize [insert topic] so deeply I could teach it to someone with zero background.
Role: You’re a master educator who turns complexity into clarity.
Command: Break this down in ultra-simple language, like I’m explaining it to a 10-year-old. Use metaphors or real-life examples where helpful.
Format: Give me a 3-paragraph explainer I can use in a team meeting or whiteboard session.
```

## How to use it
1. Replace [insert topic].
2. Paste the prompt.
3. Use the explainer in the meeting. Do not treat the shorter “explain this simply” line as a second prompt. That weaker version was only a contrast example.
