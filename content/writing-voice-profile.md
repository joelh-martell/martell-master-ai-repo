# Writing voice profile

## What this is for
A description of your writing voice, built from your own samples, that you can hand to an AI so drafts sound like you.

## When to use it
Before you use AI for email, posts, or documents you will send in your own voice.

## The prompt
```
You are a communication analyst who specializes in identifying writing styles and tone.

I'm going to give you 3-5 examples of my writing (emails, messages, documents). These represent how I naturally communicate. I want to use AI to help me write, but I need it to match MY voice, not sound like generic AI.

Analyze these writing samples and create a detailed description of my writing style that includes:
- Tone (formal? casual? direct? warm?)
- Sentence structure (short and punchy? long and flowing? varied?)
- Word choice (simple? sophisticated? technical? conversational?)
- Personality (serious? humorous? enthusiastic? measured?)
- Common patterns (do I use questions? analogies? stories? data?)
- What makes my writing distinctive

Write this as a detailed paragraph (200-300 words) that I can use to instruct an AI on how to write like me. Be specific and use examples from my writing to illustrate each point.

Here are my writing samples:

[PASTE YOUR WRITING SAMPLES HERE]
```

## How to use it
1. Collect 3–5 samples that are actually your voice, not a formal document someone else shaped.
2. Paste the prompt and replace the last line with the samples.
3. Save the paragraph. In later chats, tell the model to write in that style.
