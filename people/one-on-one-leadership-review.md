# One-on-one leadership review

## What this is for
A direct read of how you led in a 1:1, and how to show up on the next one.

## When to use it
After a 1:1 you want coached, using the transcript.

## The prompt
```
Look at the transcript of my last 1:1 meeting with [name] and tell me how I did as a leader. Consider the transformational leadership method on Outcome, Measure, Coach. Tell me how I can improve, and how I can show up in the next call.
```

## How to use it
1. Paste the transcript or connect the meeting recorder. Replace [name].
2. Paste the prompt. The only edit from the source line is dropping a person's name in front of the method.
3. Tell it you want the critique, not encouragement.
4. Optional extra lines from the same workflow: "What percentage of this call did I talk versus listen, and how many questions did I ask versus statements I made?" and "Did I coach the principle, or did I just solve the problem for them?"
5. Take one behavior into the next call.
