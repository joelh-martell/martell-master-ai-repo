# Master context interview

## What this is for
Have the model interview you, then write a master prompt you can attach to later chats so you stop re-explaining who you are.

## When to use it
Once, when you want a reusable context file for a role. Update it when the role changes.

## The prompt
```
I'm [your role] at [company type]. Create a master prompt for me. Ask me every question you need to give me the most context possible.
```

## How to use it
1. Replace the brackets.
2. Spend the time to answer what it asks.
3. Save the output and upload it to new chats or a project.
