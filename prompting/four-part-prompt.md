# Four-part prompt

## What this is for
A fill-in prompt shape: role, context, task, and output format.

## When to use it
Any time a one-line request is coming back generic. This is the blank shape, not a finished prompt for one job.

## The prompt
```
1. Act as a… [ROLE]
2. I’m trying to… [CONTEXT]
3. Create a… [TASK]
4. Format the output as… [FORMAT]
```

## How to use it
1. Replace each bracket before you send it.
2. Name a specific role, not "a helpful assistant."
3. Say what you will do with the answer so the format matches that next step.
