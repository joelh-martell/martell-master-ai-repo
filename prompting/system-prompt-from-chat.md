# System prompt from a finished chat

## What this is for
After you have already gone back and forth until the output is right, turn that chat into one reusable system prompt.

## When to use it
At the end of a chat that finally produced the output you wanted, so you do not rebuild it next time.

## The prompt
```
Write the system prompt that would have generated this output from the beginning.
```

## How to use it
1. Stay in the same chat, with the examples and edits still in the thread.
2. Paste this as the next message.
3. Save the result and reuse it. Do not start a new file for a slightly shorter wording of this same line.
